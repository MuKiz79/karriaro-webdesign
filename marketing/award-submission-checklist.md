## Demo-Video-Aufnahme-Skript (30 Sekunden, für GDA + Awwwards)

**Vorbereitung:** Desktop 2880×1800 (oder 1920×1080 für MP4-Export), Browser-Window maximiert ohne Cookie-Banner, Lenis aktiviert (smooth scroll).

| Sekunde | Aktion |
|--------:|--------|
| 0–3 | Hero static — Headline „Ihre Website. Handgemacht." + Mockup-Cycling (Stadtmakler) |
| 3–7 | Scroll smooth bis Audit-Sektion. Type-On-Placeholder zeigt verschiedene URLs. |
| 7–10 | Performance-Bar-Chart Sektion — LCP-Wert animiert sich auf 0,3 s |
| 10–14 | Werkstatt-Scrollytelling — 5 Akte mit Stagger-Reveal |
| 14–19 | Branchen-Tool-Bühne — Click auf Dachdecker → BAFA-Rechner ausfüllen → Output |
| 19–22 | Pull-Quote-Hero „Wenn Ihr Name draufsteht…" mit überhängendem Gold-Anführungszeichen |
| 22–26 | 4-Tier-Pricing — Branchen-Selector ändert Highlight |
| 26–30 | Letter-Card-Kontakt mit Stempel + Signatur — Submit-Stempel-Animation |

**Audio:** Optional Mono-Voice „Karriaro · Webdesign-Manufaktur" am Ende; oder rein visuell ohne Audio (Awwwards akzeptiert beides).

**Export:** MP4 H.264, 1080p, ≤30 MB, sRGB.
