Die vier Werkzeuge

karriaro_audit_site

Prüft eine Website auf Substanz, BFSG-Konformität, SEO und KI-Auffindbarkeit. Qualitatives Verdict („Stark", „Solide", „Ausbaufähig") + Top-Findings. Latenz 3-5 s.

karriaro_extract_voice

Analysiert den Brand-Voice nach Karriaro-Codex (Aesop/Hermès/Manufactum-Editorial vs. SaaS-Filler vs. Werkstatt-Klischee). 3 Stärken, 3 Verbesserungen.

karriaro_generate_brand_mockup

Generiert eine Hero-Mockup-SVG (480 × 320 px) für eine von acht Branchen. Folio-Eyebrow, Fraunces-Italic-Headline, Phyllotaxis-Siegel, Branchen-Farbpalette.

karriaro_phyllotaxis_signature

Erzeugt ein deterministisches Phyllotaxis-Siegel (Goldener Winkel θ = 137,5°) für einen Namen. Variation in Punkt-Anzahl, Farbe, Rotation — gleicher Name liefert gleiches Siegel.

Installation

Zwei Wege — beide ohne Kosten, ohne Anmeldung, ohne Cookie.

A · Direkt über HTTP (empfohlen)

Wenn Ihr MCP-Client HTTP-Transport unterstützt (Claude Desktop ab v0.7, Cursor, OpenAI Codex):

{
  "mcpServers": {
    "karriaro": {
      "url": "https://europe-west1-apex-executive.cloudfunctions.net/mcpHandler"
    }
  }
}

B · Lokal via npm-Package

Wenn Sie stdio bevorzugen (Air-Gap, lokale Isolation):

npm install -g @karriaro/webdesign-mcp

In claude_desktop_config.json:

{
  "mcpServers": {
    "karriaro": {
      "command": "karriaro-mcp"
    }
  }
}
