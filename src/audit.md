## Was wird geprüft

In 5 Sekunden bekommen Sie einen Bericht mit Score (0-100), Top-3-Probleme
und Quick-Wins über:

### 1. BFSG-Compliance (Barrierefreiheit, EU-Norm 2025)

- Alt-Texte auf Bildern
- ARIA-Labels auf interaktiven Elementen
- Tastatur-Navigation
- Kontrast-Ratio (WCAG 2.2 AA)
- Focus-Indikatoren

### 2. Performance (Core Web Vitals)

- LCP (Largest Contentful Paint) — Ziel: < 2,5 s
- CLS (Cumulative Layout Shift) — Ziel: < 0,1
- FID/INP (First Input Delay / Interaction to Next Paint) — Ziel: < 200 ms
- TTI (Time to Interactive) — Ziel: < 3,8 s

### 3. SEO-Foundation

- Title-Tag (Länge, Keyword-Präsenz)
- Meta-Description
- Canonical-URL
- hreflang (bei mehrsprachigen Seiten)
- robots.txt + sitemap.xml
- Schema.org-Markup (Organization, LocalBusiness, FAQPage, BreadcrumbList)

### 4. GEO (Generative Engine Optimization) — KI-Auffindbarkeit

- llms.txt-Präsenz (für ChatGPT, Claude, Perplexity, Apple Intelligence)
- Speakable-Schema (für Voice-Assistants)
- FAQ-Schema (für Featured Snippets + KI-Antworten)
- Markdown-Mirror (LLM-Crawler-Friendly)

### 5. Branchen-Standards

- Branchen-spezifische Trust-Signale (z.B. IVD für Immobilien, BÄK für Praxen)
- Notwendige rechtliche Pages (Impressum, Datenschutz, AGB, Barrierefreiheit)
- Branchen-Werkzeuge (Termin-Buchung, Preis-Rechner, etc.)

### 6. Pain-Points

- Security-Header (HSTS, CSP, X-Frame-Options, Referrer-Policy)
- Mobile-Optimierung (viewport, touch-targets ≥ 44×44 px)
- Social-Cards (Open Graph, Twitter Card)
- HTTPS + Zertifikat-Status
- PWA-Readiness (manifest, service-worker)
