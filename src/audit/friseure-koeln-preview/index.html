Friseure in Köln, vermessen.

DEMO-VORSCHAU. Diese Seite zeigt die Editorial-Schicht der Karriaro Web-Index-Engine an einer frei erfundenen Stichprobe (Domains friseur-beispiel-NN.demo). Sie wird nicht indexiert. Der echte Köln-Audit erscheint unter /audit/friseure-koeln/, sobald ein realer Scanner-Run vorliegt.

№ 06 · METHODE

Wie diese Zahlen entstanden sind.

Stichprobe. ≥ 5 öffentliche Bewertungen, OPERATIONAL, eigene Website, keine Enterprise-Domain.

Erhebung. Google Places API + PageSpeed Insights + Tech-Detect-Heuristik. Instrumentierung über die Karriaro Lead-Intelligence v2.

Anonymisierung. FNV-1a-Hash über Domain, Branche-Präfix + 3-stellige Nummer — eine Korrelation Site ↔ Kennung verbleibt allein im Datenraum der Karriaro-Manufaktur.

Mindest-Stichprobe. 30 Sites pro Branche und Stadt; darunter wird kein Report veröffentlicht.
